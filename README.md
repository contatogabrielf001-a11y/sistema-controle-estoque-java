Sistema de controle de Estoque em java

Sobre o projeto

Sistema de controle de estoque desenvolvido em java para praticar logica de programação e conceitos de desenvolvimento de software.

Funcionalidades

* Cadastro e consulta de produtos.
* Pesquisa de produtos pelo nome.
* Ediçaõ e exclusão de produtos.
* Registro de vendas.
* Atualização de estoque após as vendas.
* Historico de vendas.
* Indentificação de produtos que precisam de reposição.
* Salvamento e carregamento de dados em arquivos de texto.

Tecnologias utilizadas

* Java.
* Arraylist.
* Programação orientada a objetos.
* Manipulação de arquivos.
* Estrutura condicionais e de repetição.

Como executar

É necessário ter o Java JDK instalado.

Na pasta do projeto, execute os comandos:

javac Main.java Produto.java
java Main

Objetivo

Projeto desenvolvido para praticar Java, fortalecer a lógica de programação e construir um portfólio para oportunidades de estágio em desenvolvimento de software.
